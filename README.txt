# Mahaboob Jan Basha Shaik — Portfolio

## Preview locally
1. Extract this ZIP file.
2. Open the `mahaboob_portfolio` folder.
3. Double-click `index.html` to open it in a browser.

For best results, use a local development server such as VS Code Live Server.

## Included
- Responsive single-page portfolio
- About, skills, projects, education, experience, achievements and contact sections
- Two PhonePe Power BI dashboard screenshots (overall and filtered CREDIT/Tuesday view)
- Resume PDF

## Before publishing
1. Add your real LinkedIn and GitHub profile URLs if you want them displayed.
2. Confirm the PhonePe dashboard figures. The screenshot currently displays 337.00K total and 292.28 average, while the resume contains different figures (360.69K and 427). This version deliberately describes the dashboard without repeating the conflicting resume figures.
3. Check your contact details and resume are correct.
4. Publish using GitHub Pages, Netlify or another static hosting provider.

The website uses Google Fonts; an internet connection is needed for those fonts. The rest of the site is static.
